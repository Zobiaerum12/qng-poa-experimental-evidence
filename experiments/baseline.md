# Baseline Network Operation

## Scenario

All three authorised validators were active.

## Observations

The validators established peer connectivity and participated in normal block processing.

Runtime logs recorded graph-state synchronisation, DAG reorganisation, and continued block processing.

Representative runtime-reported single-block processing windows included approximately:

- 10.01--10.66 seconds
- 19.62--20.58 seconds

These values are runtime-reported processing windows and should not be interpreted as direct measurements of block-generation latency or finality.

## Purpose

This scenario provides the baseline reference for comparison with the validator-failure and reduced-availability experiments.
