# Raw Experimental Logs

This directory contains the original QNG runtime logs from the three-validator MyAmana Proof-of-Authority experimental deployment.

The files correspond to the three validator instances used in the experiments:

- `signer1.log` — Validator/Signer 1
- `signer2.log` — Validator/Signer 2
- `signer3.log` — Validator/Signer 3

These logs provide the underlying runtime evidence for the experimental observations reported in the manuscript, including validator operation, failure and recovery, graph-state synchronisation, DAG reorganisation, and reduced validator availability.

The logs are provided as experimental evidence and should be interpreted in the context of the specific configuration and runs documented in this repository.
